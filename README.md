# مشروع وِصال (Wisal) — المنصة الاجتماعية العربية المتكاملة

> «أكثر من مجرد تواصل»

تطبيق أندرويد حقيقي واحترافي مبني بلغة Kotlin وأحدث تقنيات Jetpack Compose وتصميم Material Design 3، بهوية بصرية عربية فاخرة مستوحاة من التصميم المرجعي، مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL) وخط Cairo العربي.

---

## 📱 مميزات التطبيق

1. **شاشة البداية (Splash Screen):**
   - شعار وِصال المتوهج مع حركة ظهور أنيقة ومؤشر تحميل.
   - عبارة الهوية: «أكثر من مجرد تواصل».

2. **المصادقة وتسجيل الدخول (Authentication):**
   - إنشاء حساب جديد وتسجيل الدخول.
   - التحقق من صحة البريد وكلمة المرور.
   - أزرار تسجيل الدخول الاجتماعي (Google, Apple, Facebook).

3. **الصفحة الرئيسية (Home Feed):**
   - شريط علوي يحمل شعار وِصال، البحث، التنبيهات، والمحادثات المباشرة.
   - شريط القصص الدائرية اليومية مع إمكانية إضافة قصتك.
   - منشورات تفاعلية: إعجاب (Like) مع عداد تفاعلي، تعليقات حقيقية ومحفوظة، مشاركة، وحفظ بالمفضلة.
   - تحديث المنشورات عند السحب للأسفل (Pull to Refresh).

4. **عارض القصص بملء الشاشة (Stories):**
   - عارض ملء الشاشة متطابق مع التصميم (قصة سارة أحمد).
   - شريط تقدم زمني متقطع.
   - أزرار الإعجاب، التعليقات، والمشاركة.
   - حقل رد مباشر «إرسال رسالة...».

5. **المحادثات الفورية (Direct Messaging):**
   - قائمة المحادثات (سارة، محمد، نور، خالد، مواهب، مجموعة الأصدقاء).
   - مؤشرات الاتصال (متصل الآن) وشارات الرسائل غير المقروءة.
   - شاشة محادثة كاملة مع إرسال وحفظ الرسائل، وردود تلقائية تفاعلية.

6. **البحث والاكتشاف (Discover):**
   - حقل بحث عن الأشخاص، المنشورات، والوسوم.
   - تصنيفات تصفية (الكل، أشخاص، منشورات، مجموعات).
   - بطاقات «أشخاص قد تعرفهم» (عمر خالد، ريم القحطاني) مع زر المتابعة.

7. **إنشاء منشور جديد (Create Post):**
   - محرر متكامل لكتابة المنشور واختيار الخصوصية (عام، الأصدقاء، خاص).
   - إرفاق الصور، الفيديو، الموقع، والرموز التعبيرية.
   - زر النشر الفوري للحفظ في قاعدة البيانات والظهور في الخلاصة.

8. **الإشعارات (Notifications):**
   - تصفية الإشعارات (الكل، متابعات، إعجابات، تعليقات).
   - تفاصيل الإشعارات وأوقاتها وحالتها (مقروءة/غير مقروءة).
   - زر تحديد الكل كمقروء.

9. **الملف الشخصي (Profile):**
   - صورة غلاف بانورامية وصورة شخصية موثقة.
   - إحصائيات الحساب: عدد المنشورات، المتابعون، ومتابعو الحساب.
   - تبويبات: المنشورات، الصور، والفيديوهات في شبكة ثلاثية أنيقة.
   - إمكانية تعديل الملف الشخصي والنبذة التعريفية.

10. **الإعدادات والخصوصية (Settings):**
    - تبديل المظهر بين الداكن والفاتح (Dark / Light Mode).
    - الحساب والخصوصية والإشعارات والدعم الفني.
    - تسجيل الخروج الآمن.

## 🚀 طريقة بناء وتنزيل ملف الـ APK عبر GitHub من هاتفك

1. **رفع المشروع إلى GitHub:**
   - ادخل إلى حسابك في GitHub وأنشئ مستودعًا جديدًا (Repository).
   - ارفع ملفات هذا المشروع إلى المستودع.

2. **بناء التطبيق تلقائيًا (GitHub Actions):**
   - يحتوي المشروع مسبقًا على ملف الإجراءات جاهزًا في:
     `.github/workflows/build-apk.yml`
   - بمجرد رفع الكود (Push)، سيبدأ GitHub Actions تلقائيًا في بناء التطبيق.
   - يمكنك أيضًا تشغيله يدويًا من الهاتف:
     - افتح صفحة المستودع على الهاتف.
     - اضغط على تبويب **Actions**.
     - اختر **Build Android APK (Wisal)** واضغط على **Run workflow**.

3. **تنزيل ملف APK:**
   - بعد انتهاء البناء (يظهر علامة صح خضراء ✅):
   - اضغط على مسار التشغيل المكتمل.
   - انزل لأسفل الصفحة إلى قسم **Artifacts**.
   - اضغط على **Wisal-Debug-APK** لتنزيل ملف الـ ZIP الذي يحتوي على تطبيق `app-debug.apk`.
   - افتح الملف وثبته على هاتفك فورًا!

## 🛠️ البنية التقنية

- **لغة البرمجة:** Kotlin 2.2.10
- **واجهة المستخدم:** Jetpack Compose (Material Design 3)
- **قاعدة البيانات والتخزين المحلي:** Room Database + KSP + Coroutines & Flow
- **الخطوط والأصول:** خط Cairo العربي المحلي عبر `font-util`
- **معمارية المشروع:** MVVM + Clean Architecture (Data -> Repository -> ViewModel -> UI Components & Screens)
